# Arg0s

Orquestador local de tareas de IA: enruta tareas a modelos heterogéneos (cloud y locales),
aplica estrategias de ejecución adaptativas (router / fusion / judgment day), compila
contexto mínimo desde memoria y código, y mide empíricamente su propio rendimiento.

Especificación completa: [docs/ARG0S.md](docs/ARG0S.md).
